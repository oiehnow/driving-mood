**실제 파인튜닝을 수행했지만, 첫 파일럿에서 전반적인 개선은 확인하지 못했다. 제품 기본 모델은 공식 사전학습 모델로 유지한다.**

YOLO26n-sem-ADE20K의 기존 150개 클래스를 유지한 채 30 epoch, 180회의 optimizer step을 실행했다. 현재 앱의 건물·창문·간판·차량 분류와 320 크기 모바일 입력 경로에 호환되는 작은 모델이므로 선정했다. 구조를 새로 바꾸기보다 같은 모델의 제한적인 도메인 적응을 확인하는 실험이었다.

학습에는 3개 원본 영상에서 뽑은 12장, 검증에는 별도 영상 4장을 사용했다. AI가 실제 RGB를 보고 일부 확실한 영역만 주석했으며, 자동 예측 마스크를 정답으로 복사하지 않았다. 사람이 검수한 전체 정답은 아니다. 불명확한 영역은 255로 표시해 학습과 평가에서 제외했다.

학습에 사용하지 않은 다른 2개 원본 영상의 8장으로 독립 평가했다. 주석된 100,927픽셀은 평가 이미지 전체의 약 5.48%다. 같은 원본 영상의 인접 프레임이 서로 다른 split에 들어가지 않게 분리했다. 검증 점수로 선택된 epoch 2의 모델을 한 번 평가했으며, 평가 결과로 설정이나 정답을 수정하지 않았다.

어두운 도로의 일부 노면 분류는 개선됐지만, 주간 보도를 도로로 잘못 분류하는 퇴행이 나타났다. 넓은 도로 영역의 개선으로 픽셀 정확도가 올라가더라도 클래스 평균 성능이 함께 좋아지는 것은 아니었다. 개선 사례와 퇴행 사례, 두 모델 모두 틀린 사례를 모두 보존했다.

이 평가는 AI 보조 부분 주석과 소수 영상에 한정된다. 학습용 320 격자에서 창문·사람은 각각 59픽셀, 보도는 32픽셀로 매우 적었다. 미주석 경계와 먼 불빛의 정체는 평가하지 않았다. 전체 장면의 일반화, 간판 재현율, 차량광 완전 제외, 휴대폰 정확도 향상을 주장하지 않는다. 실제 학습을 수행했다는 사실과 제품 성능이 개선됐다는 판단을 구분한다.

독립 평가 후 재튜닝이나 기본 모델 교체는 하지 않았다. 다음 실험에는 더 다양한 원본과 별도의 사람 검수 주석, 새로운 독립 평가 자료가 필요하며, 이번 평가 자료로 설정을 반복 선택하지 않는다.
