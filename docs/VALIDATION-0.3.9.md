## 비용과 실제 적용 범위

Android 15 x86_64 에뮬레이터의 CPU 분석 경로에서 준비 후 프레임당 중앙값은 약 1.65초였다. 처음 모델을 준비한 호출은 약 2.12초, 이후 범위는 약 1.60~2.15초였다. 촬영·디코딩·전체 구간 누적 시간은 제외했다. 최종 호출 후 PSS는 약 173MiB이며 추론 중 최대값은 아니다. 초기 arena 설정에서 관측된 높은 잔류 메모리와 최적화 전후 실행도 보존했다.

사용자 영상의 동결한 실제 RGB로 검사했으며 새 카메라 촬영, 실휴대폰·실차 속도나 발열을 확인한 것은 아니다. API 통신과 음악 재생의 기존 UI 검증, 모델 정확도, 계산 정합, 제품 실행 비용을 서로 다른 항목으로 관리한다. 기존 앱 화면은 0.3.8 촬영본이다.

## 보존한 실패와 남은 과제

Pilot01/02, A/B/C 단독 교체, 입력 해상도·모델 크기 확대, F1의 실패를 기록했다. F2는 부분 주석의 개발 기준과 선택 후 보조 평가를 통과했다. 이 결과를 전체 화면 정답이나 감성 정확도로 해석하지 않는다.

초기 검사 준비 과정의 signed-byte fixture 변환 오류, PT 검출 head 형태 불일치도 수정 경위를 남겼다. 화면을 포함한 기존 native 검사는 완료되지 않아 중단했으며 성공으로 집계하지 않았다. 이후 UI를 포함하지 않는 모델 검사와 실제 AppServices 검사로 분리했다. APK 검사에서는 설명 metadata의 경로와 숫자 가중치를 문자열로 읽어 발생한 오탐을 구분해 수정했다.

남은 검증은 창문·작은 간판 정답 보강, 발광·반사·차량광 속성 평가, 출처가 분리된 전체 장면 검수, 대상 단말의 전체 요청 지연·최대 메모리·발열이다. Pleos 0.1.1은 별도 UI 시연 앱이며 복합 모델과 실차 카메라의 연결은 후속 작업이다.
