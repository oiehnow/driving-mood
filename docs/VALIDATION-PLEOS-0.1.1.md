최소화 상태에서 에뮬레이터의 실제 오디오 출력을 5초 녹음했다. 오디오 패킷 461개와 평균 음량 −17.7dB를 확인했다. 원본 MP3를 영상에 별도로 덧씌운 검증이 아니다.

전체화면 및 3분할 MP4는 화면 녹화와 같은 시점의 실제 에뮬레이터 출력 음성을 결합했다. 시작 시각으로 정렬했으며 화면 인코더의 시작 지연은 측정하지 않아 프레임 단위 동기화를 보장하지 않는다. 영상 마지막 2초에는 음악과 화면에 함께 페이드아웃을 적용했다. GIF는 무음이다.

APK SHA-256: `aaa15c8728ebf054e3136fba4f0919268912593e3c9788dda05a161201c785e5`.

무드와 점수는 새벽 고속도로를 가정한 수동 예시다. 음악은 기기의 실제 로컬 파일을 재생하며, 조명은 화면에서 색상·밝기를 확인하는 기능이다. 차량 조명 제어와 영상 분석은 이 모듈에 연결하지 않았다. SDK의 안내 상태와 내비 화면이 일치하지 않는 경우 ‘안내 상태 확인 필요’로 표시한다.
