# 주행 장면 파인튜닝 파일럿

차량 주행 영상과 이미지 자료를 보강한 [2차 학습과 검증 결과](finetuning02/README.md)도 보존했다. 2차 후보는 개발 검증 평균 IoU를 높였지만 간판 오탐과 기존 보도·사람 성능이 악화돼 공식 기준 모델을 유지했다.

2026년 10월 24일, 공식 YOLO26n-sem-ADE20K에서 실제 추가 학습을 수행했다. 도로 분류는 개선됐지만 클래스별 평균 IoU가 낮아져 0.3.1의 기본 모델은 공식 가중치로 유지했다.

![학습 손실과 독립 시험 결과](../product/assets/finetune-pilot01.png)

## 모델 선택

무드 계산에는 물체의 존재뿐 아니라 건물·창문·간판·차량·도로 중 어느 영역에서 빛이 관측되는지가 필요하다. ADE20K의 150종 의미분할은 이 영역들을 함께 제공한다. Cityscapes에는 창문과 상점 간판을 직접 구분할 클래스가 없고, 객체 검출만으로는 사각형 안의 빛과 주변 픽셀을 분리하기 어렵다. 색감과 밝기는 분할된 원본 RGB에서 측정하고 무드 기여 점수는 별도 규칙으로 계산한다.

nano 크기를 선택한 근거는 320 입력의 모바일 ONNX/ORT 변환 경로와 Android 실행 검증, 기존 장면 비교다. 큰 모델도 작은 간판·반사·차량 내부 오분류를 모두 해결하지 못했으므로, 같은 구조를 주행 영상에 적응시키는 실험부터 수행했다. 모델 크기만으로 정확도나 실차 성능을 판단하지 않는다.

## 데이터와 학습

| 구분 | 분리 기준 | 용도 |
|---|---|---|
| 학습 | 원본 영상 단위 | 가중치 갱신 |
| 검증 | 학습과 다른 원본 영상 | 체크포인트 선택 |
| 시험 | 학습·검증과 다른 원본 영상 | 선택 완료 후 독립 비교 |

영상 전체를 분리해 인접 프레임이 다른 집합에 섞이지 않게 했다. 실제 RGB를 검토한 AI 보조 부분 폴리곤을 사용했으며, 사람 검수를 마친 전체 화면 정답은 아니다. 불명확한 경계·가림·빛 번짐은 255로 제외하고 ADE20K의 0~149 ID를 유지했다. 0은 벽 클래스다. 원본 영상과 학습용 RGB·마스크는 이 자료에 포함하지 않았다.

Ultralytics 8.4.184의 공식 semantic trainer로 320 입력, batch 2, AdamW 학습률 0.0001, seed 20261024를 사용해 30 epoch를 실행했다. 앞 11개 layer를 동결하고 optimizer를 180회 갱신했다. 검증 집합의 fitness로 2회차 체크포인트를 선택했으며 시험 결과는 선택에 사용하지 않았다.

초기와 선택 모델을 비교해 104개 state tensor의 변화를 확인했다. 이 수에는 학습 가중치와 실행 통계가 함께 포함된다. [고정 설정](finetune-pilot01/training-config.json), [30회 기록](finetune-pilot01/epochs.csv), [가중치 해시·변환·평가 원장](finetune-pilot01/evidence.json), [학습 코드와 재현 절차](../../models/semantic/finetuning-pilot01/README.md)에 실제 실행 증거를 제공한다.

## 평가와 채택 판단

서로 다른 원본 영상에서 분리한 시험 자료의 주석 영역에서 같은 전처리의 두 ONNX 모델을 비교했다.

| 지표 | 공식 가중치 | 추가 학습 |
|---|---:|---:|
| 정답이 있는 8개 클래스 평균 IoU | 60.44% | 58.76% |
| 픽셀 정확도 | 82.31% | 86.19% |
| 도로 IoU | 70.47% | 79.80% |
| 보도 IoU | 62.80% | 39.51% |
| 창문 IoU | 0% | 0% |
| 간판 IoU | 0% | 0% |

넓은 도로의 개선이 픽셀 정확도를 높였지만 보도와 작은 조명 관련 클래스까지 개선하지는 못했다. 부분 주석의 클래스 불균형이 크고, 특히 창문·간판 표본이 부족하다. 이번 평가는 주석 영역의 의미분할 비교이며 전체 경계 품질이나 차량광 제외율을 측정한 것은 아니다.

선택 모델은 기존 320 RGB 입력·150종 uint8 클래스맵 계약으로 ONNX와 ARM Fixed ORT 변환을 마쳤다. 학습·검증 자료의 출력 픽셀을 비교했을 때 PyTorch→ONNX에서 1픽셀, ONNX→ORT에서 2픽셀이 달랐다. 양자화는 적용하지 않았다.

별도 연구 APK에서도 두 모델을 비교했다. 모델별 자동 검사 261개와 네이티브 검사 7개를 통과했고, 동일 RGB·추론 텐서 14개에서 Android와 데스크톱 ORT의 클래스맵 차이는 0이었다. 30초·60초 촬영 완주와 취소 후 정리도 확인했다. [Android 비교 기록](finetune-pilot01/android-verification.json)은 Android 15 x86_64 에뮬레이터 결과이며 실제 휴대폰·차량 성능과 구분한다.

기본 모델 교체에 필요한 개선 근거가 부족해 학습 후보와 기준 모델을 함께 보존했다. 다음 학습은 여러 원본 영상에서 낮·밤·비·도심·고속도로 장면을 고르게 확보하고 창문·간판·보도와 차량 경계의 주석을 보강한다. 같은 원본의 짧은 클립과 풀버전은 같은 그룹으로 묶고, 영상별 표본 수를 제한해 긴 영상에 학습량이 쏠리지 않게 한다. 이번 시험 집합은 회귀 확인용으로 보존하며, 다음 최종 평가는 미사용 원본 영상과 사람 검수 주석으로 구성한다.
