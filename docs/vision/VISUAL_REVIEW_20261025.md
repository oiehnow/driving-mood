# baseline/F2 장면 분할 시각 검토 — 2026-10-25

F2는 일부 장면의 하늘 누락을 줄였지만, 건물 외벽·창·트럭을 간판으로 넓게 분류하는 악화도 보였다. 요금소의 노을 하늘, 개별 창문, 차도와 보도 경계, 일부 사람·차량 누락은 여전히 남아 있다. 이 기록은 AI 정성 교차검수이며, 모델의 전체 정확도나 실차 품질을 입증하는 평가가 아니다.

## 비교 방법과 해석 범위

기존 개발에 사용한 영상에서 재생 길이의 20%, 50%, 80% 지점을 미리 정해 추출했다. 각 검토자는 예측을 보기 전에 원본의 하늘·건물·창문·표지·차도·보도·차량·사람 및 불확실한 영역을 기록했다. 이후 모델 이름을 가린 A/B 오버레이와 필요한 개별 마스크를 실제 이미지로 비교하고 판단을 동결했다. 모든 비교 판단을 동결한 뒤 프레임별 A/B 매핑을 열어 아래의 baseline/F2 이름으로 환산했다.

- baseline은 기존 패키지의 320 의미 분할 모델이다. F2는 기존 baseline, 640 하늘 보조 모델, C320 구조 보조 모델과 고정된 융합 규칙을 적용한 결과다. 이번 검토에서 모델·규칙·임계값을 새로 학습하거나 조정하지 않았다.
- 같은 개발 영상을 다시 사용했다. 중간 시점은 이전 개발 구간과 중복되며, 나머지 시점도 과거 사용 여부를 전부 확인한 독립 검증 자료가 아니다.
- 원본 관찰과 비교는 AI가 수행했다. 사람의 정답 라벨이나 전체 픽셀 정답을 만들지 않았으며, 정확도·개선율·승률·통계적 우월성을 계산하지 않는다.
- 원본 크기로 표시한 마스크는 낮은 해상도 예측을 원본 좌표에 투영한 것이다. 원본 해상도로 새 추론을 했다는 뜻이 아니다.
- 야간 HDR 입력은 고정된 HDR→SDR 변환을 거친 표시 영상이다. 이 결과만으로 원래 HDR 색·광량의 정확성이나 조명 인식 품질을 입증하지 않는다.
- 검토에는 저장된 오프라인 입력을 사용했다. Android 영상 디코더·축소 방식과의 동일성, Android 실행 시간, 실제 촬영 환경에서의 성능은 별도 검증 대상이다.
- 장면 분위기와 운전자의 자기보고 기분은 별개다. 영상이나 삽입된 문구로 운전자의 감정·우울 상태 또는 올바른 무드·음악을 판정하지 않았다.

## 의미 분할과 객체 탐지는 다른 결과다

위 A/B 판정은 픽셀 단위 의미 분할 결과에 대한 것이다. 별도로 표시한 현재 객체 탐지기의 상자·신뢰도는 의미 분할의 정답이나 개선 증거로 사용하지 않았다. 이전 객체 탐지기를 같은 조건으로 실행한 비교도 없으므로 탐지기 교체 효과를 결론 내릴 수 없다.

표시 클래스와 저장된 마스크를 추가로 대조한 결과, 아래 누락은 오버레이 색상이나 표시 과정의 유실이 아니라 최종 의미 분할 출력에 존재했다.

- full-02-p20: 오른쪽 보행자는 최종 의미 분할의 person 레이어에 없다. 별도 탐지기는 해당 사람 후보를 신뢰도 약 0.316으로 표시하지만, 시각화 기준 0.25를 넘는 것과 앱의 사람 관측 기준 0.5를 통과하는 것은 다르다. 이 사례를 ‘앱에서 보행자 검출 성공’으로 기술하지 않는다.
- full-02-p80: 전방 차량은 양쪽 최종 의미 분할의 vehicles 레이어에 없다. 별도 탐지기에는 차량 후보가 있으나 같은 좌표의 car/truck 중복도 있다. 표시된 상자 수를 서로 다른 실제 차량 수로 해석하지 않는다.
- 640 보조 모델의 원시 출력에는 사람·차량 클래스로 분류된 일부 픽셀이 있으나, 고정된 융합은 이 보조 출력을 하늘 복원에만 사용하므로 사람·차량 복구로 이어지지 않는다. 보조 출력에 픽셀이 있다는 사실 자체도 그것이 정답임을 보증하지 않는다.

기존 baseline의 사람·차량 분류를 보호하는 규칙은 그 영역이 추가 모델 때문에 덮이는 것을 제한한다. 그러나 baseline이 이미 놓치거나 잘못 분류한 물체를 복구하는 검증 장치는 아니다. ‘보호되어 변하지 않았다’는 결과를 ‘올바르다’ 또는 ‘독립적으로 확인되었다’로 설명하면 안 된다.

또한 제공된 sign은 통합 표시 레이어다. 원본에서 상업 광고판과 교통 표지를 구별해 관찰했더라도, 통합 레이어 비교만으로 내부 모델이 두 종류를 올바르게 구분한다고 입증할 수 없다.

## 다음 개선과 검증

아래는 후속 작업 제안이며 이번 검토에서 시행한 변경이 아니다.

1. **실패 영역을 검수 주석으로 명확히 한다.** 요금소 하늘, 외벽과 창문, 실제 상업 간판과 도로 표지, 차도와 보도, 사람·차량을 구분해 누락·과확장·경계 오류를 기록한다. 작거나 가려진 물체와 정밀한 가지 경계에는 불확실성 표시를 남긴다. AI 관찰을 그대로 사람 정답으로 전환하지 않고 검수 절차를 거친다.
2. **하늘 개선과 sign 악화를 함께 평가한다.** 하늘의 누락만 줄어든 결과를 선택 기준으로 삼지 않는다. 실제 간판의 누락뿐 아니라 창·벽·트럭·도로 표지 주변의 잘못된 sign 확장을 별도 확인한다. sign이 늘어난 영역을 추가 도시 조명 근거로 바로 사용하는 것도 재검토 대상이다.
3. **보호 영역의 기존 오류도 수정 대상으로 포함한다.** 사람·차량 보호는 기존 누락과 오탐을 고칠 수 없다. 보조 분할과 탐지기의 불일치, 중복 상자, 관측 임계값 통과 여부를 검수하고, 기존 오류 복구와 새 오탐 방지를 함께 검증할 수 있는 수정안을 마련한다.
4. **새 영상으로 변경 효과를 검증한다.** 현재 개발 영상과 겹치지 않는 촬영 경로·시간·날씨·카메라 조건을 별도로 확보하고, 선택 기준과 판정 항목을 결과 확인 전에 정한다. 수정에 쓰인 영상과 최종 검증 영상을 구별한다.
5. **실제 앱 입력과 누적 관측으로 확인한다.** Android의 디코딩·방향·축소·융합 출력 및 짧은 촬영 동안의 반복 관측을 검증한다. 한 프레임의 객체 누락이나 잘못된 밝은 영역이 최종 장면 근거로 어떻게 누적되는지 확인한다. 실행 시간은 실기기에서 별도로 측정한다.

## 이번 기록의 변경 범위

이번 작업은 기존 모델 결과를 시각적으로 비교하고 이 문서에 남긴 것이다. 앱 코드, 모델 가중치, 융합 규칙, 학습 과정 및 임계값은 변경하지 않았다. **기존 PDF도 수정하거나 재생성하지 않았다.** 원본 영상·이미지·개인 PC 경로·음악 가사는 이 문서에 포함하지 않는다.
