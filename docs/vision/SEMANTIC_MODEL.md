# 의미분할 보조 관측

YOLO26n-sem-ADE20K의 건물·창문·간판 분할과 EfficientDet-Lite0의 사람·차량 검출을 함께 사용한다. 의미분할은 관측할 표면을 좁히며, 무드 점수는 실제 RGB의 색 분포·채도·밝은 면적에서 계산한다.

- 입력: RGB / 255, FP32 NCHW `[1, 3, 320, 320]`. 종횡비를 유지하고 114 회색으로 중앙 패딩한다.
- 출력: uint8 `[1, 320, 320]`, ADE20K 150개 클래스의 ID. 클래스 확률로 사용하지 않는다.
- 관측: 패딩을 제거한 같은 RGB 격자에서 국소 대비와 넓은 밝은 면을 구한다. 겹친 픽셀은 한 번 계산한다.
- 제외: 검출 차량·교통 시설, 의미분할 차량·도로 등의 영역과 차량 주변 반사 영역을 사용한다. 누락된 작은 차량광은 추가 오류 평가 대상이다.
- 점수: `semantic-contrast-mobile-v1` 통계를 `scene-v2.0`에 전달한다. 강도와 품질을 분리하며 품질 미평가를 확률로 바꾸지 않는다.

모델·버퍼는 직렬 분석기에서 재사용하고 촬영 영상은 분석·취소 후 삭제한다. ORT 텔레메트리는 ContentProvider 초기화 전에 비활성화한다.
