# 파인튜닝 2차 검증: 공식 기준 모델 유지

학습 후보 Pilot02는 개발 검증의 종합 점수를 높였지만, 간판 오탐과 기존 보도·사람 성능 퇴행으로 앱에 채택하지 않았다. 공식 사전학습 모델을 유지한다.

학습 24장·개발 검증 8장에 AI 부분 다각형 주석 135개를 만들었다. 기존 설정으로 30에폭, 360회 업데이트를 수행했고, 개발 검증으로 선택한 5에폭 체크포인트에서 104개 텐서의 값 변화를 확인했다.

| 평가 항목 | 공식 기준 | Pilot02 | 변화 |
|---|---:|---:|---:|
| 개발 검증 · 평균 IoU | 41.98% | 48.26% | +6.28%p |
| 기존 회귀 · 평균 IoU | 60.44% | 53.38% | -7.06%p |
| 간판 · 개발 검증 | 62.18% | 44.73% | -17.45%p |
| 보도 · 기존 회귀 | 62.80% | 24.19% | -38.61%p |
| 사람 · 기존 회귀 | 98.63% | 77.59% | -21.04%p |

간판 주석 616픽셀 중 정분류는 **383→475픽셀**로 늘었다. 그러나 다른 주석 영역을 간판으로 잘못 분류한 픽셀도 **0→446**으로 늘어 간판 IoU가 하락했다.

![공식 기준 모델과 Pilot02의 평균·주요 클래스 IoU 비교](finetuning02-results.png)

두 모델은 같은 입력과 원본 주석 격자에서 비교했다. 평균 IoU는 주석이 있는 클래스의 평균이다. 개발 검증 8장과 이미 평가했던 고정 회귀 8장에 대한 AI 부분주석 비교이며, 미주석 영역의 오탐과 전체 경계는 측정하지 않는다. 학습기 자체 검증 수치와는 구분했다.
