# 장면 다양성과 검증 자료

Driving Mood는 몇 개의 주행 영상에만 색과 무드 규칙을 맞추지 않도록 **주행 영상과 서로 다른 지역·저작자의 실사진**을 함께 준비한다. 하늘색뿐 아니라 상점·주거 창문, 간판·교통신호, 차량광·노면 반사의 구별을 다룬다.

## 확보한 자료

| 자료 | 확인 범위 | 현재 용도 |
|---|---|---|
| 노을·서울 낮·서울 밤·도로 주행 영상 4개 | 총 약 3시간 13분; 영상별 5장, 총 20장 추출·기준 모델 분석 | 시간 변화와 실제 주행 장면의 개발 표본 |
| Wikimedia Commons 실사진 43장 | 저작자 38그룹; 주 검토 후보 38장·보조 3장·제외 2장 | 색·광원·기상 조건 보강과 주석 준비 |
| Open Images 사진 4장·객체 마스크 6개 | 공식 validation 자료, 개별 사진 이용 조건 확인 | 외부 주석 형식과 클래스 대응 검토 |

Commons 자료는 원본 6장과 공식 축소본 37장이다. 실제 내려받은 해시와 제공 원본의 해시를 구별하고, [사진별 저작자·출처·사용 조건](external-scene-sources.json)을 보존한다. 검색어를 그대로 학습 정답으로 쓰지 않는다.

## 보강하는 장면

| 대상 | 포함할 차이와 혼동 사례 |
|---|---|
| 하늘 | 푸른 여명, 금빛·붉은·분홍·보라 노을, 박명, 맑고 흐린 낮 |
| 건물 조명 | 상점 전면과 주거 창문, 작은 세로 간판과 넓은 밝은 면 |
| 도로 광원 | 전조등·후미등, 가로등·교통신호, 젖은 노면 반사 |
| 기상·도로 | 비·안개·눈, 터널 출입구, 도심과 고속도로 |

현재 묶음에는 비 오는 전방 도로, 다양한 주거 창문, 교통신호·차량용 터널과 외부 고속도로 자료가 부족하다. 장노출 궤적과 흐릿한 광원은 개별 차량·신호등의 정답으로 사용하지 않는다.

## 확인한 개선 과제

새 영상 20장의 기준 모델 관측에서는 넓은 하늘과 도로를 구획한 사례와 함께, 다음 오류가 보였다.

- 요금소 구조물·방호벽 일부가 차량으로 분류됨.
- 대형 트럭 일부가 건물로 분류됨.
- 어두운 건물·작은 창문·간판의 구획이 누락됨.
- 도로 안내판과 상점 간판이 같은 의미분할 범주에 포함됨.

이 기록은 실제 예측의 시각 검토다. 주석을 준비한 뒤 클래스별 성능과 무드에 전달되는 오류를 따로 비교한다. [이전 파인튜닝의 개선·퇴행 기록](FINETUNING.md)은 그대로 보존한다.

## 학습·평가 원칙

영상은 파일 단위, 웹 사진은 저작자·연작 단위로 분리해 인접 프레임이 학습과 평가에 섞이지 않게 한다. 이미 살펴본 개발 자료를 새로운 독립 평가로 재명명하지 않는다. 긴 영상의 길이만큼 학습 비중을 늘리지 않는다.

사진 수준 설명·박스·부분 마스크·전체 의미분할은 다른 종류의 주석이다. 확실히 주석한 영역만 학습에 쓰고 나머지는 무시 영역으로 둔다. 현재 수집 묶음은 픽셀 정답과 감성 정답이 완성된 데이터셋이 아니다. 공식 validation 표본은 학습 묶음으로 이동하지 않는다.

서울 밤 영상은 HLG HDR이므로 고정 변환한 SDR 검수본과 색 변환 기록을 보존했다. 학습용 색 정규화는 별도로 검증하며, 영상의 촬영 시각을 다운로드 시각으로 대체하지 않는다.

공개 사본의 덧씌운 곡명·자막·모서리 워터마크는 블러 또는 모자이크로 처리한다. 분석 입력 원본과 별도 출처·라이선스 기록은 보존한다.
