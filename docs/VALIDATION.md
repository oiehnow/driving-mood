## 녹화에서 결과까지

실제 에뮬레이터 카메라로 30초·60초 파일을 녹화하고 MediaCodec의 실제 시각에 따라 30개·60개 프레임을 분석했다. 기본 의미분할 분석기, 누적 점수기, 결과 화면, 완료 신호 한 번까지 연결됐다. 촬영 중 백그라운드 이동과 디코딩 중 취소에서는 자동 재시작 없이 임시영상이 삭제됐다. 완료음은 SoundPool 스트림 생성을 확인했다.

최종 APK와 녹화 검사 APK의 차이는 모델 출처 고지 파일 하나뿐이다. DEX·Manifest·리소스·모델·네이티브 라이브러리는 동일하며, 최종 서명 APK에서 구성·라이선스와 RGB 추론을 다시 검사했다.

## 실제 장면과 모델 연결

보존한 주행 RGB 3장면을 가로·회전 세로와 기존·의미분할 경로로 실행해 12개 결과를 비교했다. 정리 전후 모델의 관측 픽셀·색 분포·채도 합·영역 수·점수는 동일했다. 회전 세로는 방향 검사용 입력이다.

작은 간판과 건물 조명의 관측 복구는 [동일 장면 비교](product/ARCHITECTURE.md)와 [주행 시연](product/VIDEO_DEMO.md)에 제시한다. 차량광 제외 성공 여부는 박스 표시가 아니라 실제 제외 마스크와 최종 선택 픽셀로 평가한다.

## 공개 소스와 고지

앱의 AGPL-3.0 고지와 원문 LICENSE, 모델·ORT·MediaPipe·Pretendard의 출처와 원문을 보존했다. 모델 설명의 불필요한 학습 경로를 제거했으며 가중치와 나머지 메타데이터는 유지했다. 기존 MediaPipe 4개 원본 바이너리의 제작사 빌드 경로는 원본 해시로 구분한다.

## 실제 기기에서 확인할 항목

Galaxy S25+의 촬영·GPS·기상청 실통신·음원 청취·발열과 지속 실행, 야간 주행 인식 정확도는 실기기 평가 대상이다. 에뮬레이터의 처리 시간은 휴대폰이나 차량 성능으로 환산하지 않는다. 내비게이션과 실차 조명 연결은 별도 입력·출력 어댑터로 확장한다.
