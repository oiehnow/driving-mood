## 50초 관측과 추천

권한 확인과 환경 조회 후 실제 카메라를 50초 동안 관측합니다. 1초 구간별 첫 프레임을 최대 50개 보관하는 C의 SceneAccumulator를 앱과 점수기가 공유합니다. 같은 사람의 반복 검출을 누적 인원으로 합산하지 않습니다. 관측 종료 후 카메라를 먼저 멈추고 누적 결과로 추천을 즉시 계산합니다.

단조 시각을 기준으로 프레임 수신 시각과 콜백 도착 시각이 모두 관측 창 안에 있는지 확인합니다. 경계 이후·이전 요청·중복·역순 프레임 배제, 취소 후 초기화, 실패 시 부분 결과, 카메라 중지 순서, 권한 거절 시 이전 창 미재사용을 검사했습니다. 전체 제한은 110초, 환경 단계 35초, 카메라 안전 제한은 60초입니다. 실제 CameraX 자원 해제와 네이티브 추론은 실기기 검증 범위로 남습니다.

Activity/Robolectric 검사에서 중복 분석 방지, 권한 창과 실제 백그라운드 이동 구분, 늦은 권한 응답 무시, 회전 후 완료 결과·분석 시각·누적 창 보존, 취소 시 이전 완료 결과 복구를 확인했습니다. 원하는 분위기 10종의 다중 선택·해제와 음악 갱신은 같은 완료 snapshot을 재사용합니다.

## 실제 영역과 점수 원장

B의 실제 프레임 관측에 사람 검출 수·박스 합집합 면적, 차량 제외 주변 빛 후보, 출처가 있는 영역을 연결했습니다. Android의 의미 분할 관측은 현재 null입니다. 사람 수는 프레임 검출 수이며 실제 인원 합계나 추적 ID가 아닙니다.

카메라 영역 표시의 FIT_CENTER 좌표 계산과 잘못된 좌표 거절을 검사했습니다. 현재 프레임만 담은 별도 창으로 C의 같은 점수기를 호출하며, 같은 요청·프레임·1.5초 이내에 도착한 기여만 표시합니다. 한 번에 하나의 점수 계산만 진행합니다. 중지·취소·지연 시 영역을 지웁니다. 실제 휴대폰 화면의 박스 정렬과 렌더링은 아직 확인하지 못했습니다.

박스별 기여 합계가 실제 그룹 기여와 일치해야 숫자를 표시합니다. 과거 창 참조, 없는 영역 ID, 중복 참조나 불일치 합계를 거절합니다. 차량에는 제외 이유를 표시하며 임의 감점을 만들지 않습니다. 라벨은 숫자를 우선 표시하고 측정한 글자 폭으로 줄입니다. 최대 8개 주요 라벨과 겹침 회피를 적용했으며, 표시 개수 제한은 전체 계산 근거를 줄이지 않습니다.

완료 화면은 최종 50초 점수와 **점수와 관측 근거** 원장을 제공합니다. 각 관측값·실제 기여·미반영 이유·규칙 버전을 보여 줍니다. 값이 없는 null과 유효한 0을 구분하며 없는 감점을 만들지 않습니다. 점수는 초기 휴리스틱 0~100으로, 감정·영업·상권의 인식 확률이 아닙니다.

## B·C 연결 검사

실제 UrbanLightAnalyzer에 작성한 픽셀과 모의 검출기 출력을 전달한 뒤 실제 누적·추천 코어를 실행했습니다. 따뜻한/차가운 색감 연결, 초반 관측 유지, 시간 미제공 시 현재 시간대 키워드 차단, 색감 단독 몽환적인 추론 제거, 근거 누락 시 임의 잔잔함·편안함 생성 방지를 검사했습니다.

사람과 주변 빛의 독립 근거, 분포된 여러 빛 후보를 통한 활력 경로, 단일 밝은 영역의 불충분 처리, 차량 이중 감점 방지, 고속도로 억제, 영역 기여 합계와 점수 상한을 검사했습니다. 제공된 의미 분할 측정의 제한 기여는 데스크톱 계약에만 해당하며 Android 앱에서 의미 분할이 실행된다는 뜻이 아닙니다. 품질 미평가 값을 확률로 채우지 않습니다.

### 0.2.5 간판 빛 계약과 중복 제외

공용 `signLightRegions`에 간판 성분별 유효 밝은 면적, 실제 채택 주변 빛과 겹치는 면적, 그 중복을 뺀 면적을 연결했습니다. 목록 null은 미측정, 빈 목록은 측정된 성분 0개이며 기존 성분의 실제 0행은 보존합니다. 완전한 영역 ID·성분 수, 유한 비율·면적 관계, 잘못된 입력 거절과 누적 목록의 양방향 방어 복사를 검사했습니다.

점수는 중복을 뺀 실제 밝은 면적만 사용합니다. 위치 미상에서도 제한적인 시각 근거를 허용하고 유효한 고속도로 정보에서는 억제합니다. 기존 전체 간판 면적이나 프레임 전체 밝기 합계만으로 점수·박스별 배분을 만들지 않습니다. 각 시간 구간의 상한·품질을 적용한 기여를 해당 구간의 실제 면적 비례로 나누고, 측정된 0참조까지 보존해 합계가 일치하는지 검사했습니다. 0점은 ‘추가 기여 없음’, null은 미반영으로 표시합니다. 아주 작은 양수는 소수 한 자리 표기에서 `+0.0점`으로 보일 수 있으며 원시 값이 0으로 바뀌는 것은 아닙니다.

B의 선택적 픽셀 근거 API는 실제 채택 주변 빛과 의미 측정에 쓸 수 있는 밝은 픽셀을 같은 격자로 반환합니다. 기본 호출에서는 배열을 만들지 않으며 기존 수치 동일성, 하드 제외 픽셀 재유입 방지, 두 마스크의 포함 관계, 프레임별 배열 소유권을 검사했습니다. 작은 간판 후보를 늘리는 형상 대칭·문자 묶음·임계값 완화는 제품에 채택하지 않았습니다. 이 변경과 검사의 통과는 실제 영상 간판 검출률이 개선됐다는 증거가 아닙니다.

환경 검사는 모의 위치·시계·통신으로 캐시 재사용, 10분 갱신 구간·격자 변경, 실패·쿼터 대기, 취소 후 늦은 응답 배제, 키 인코딩과 제한시간을 확인합니다. 실제 기상청 서버 호출은 수행하지 않았습니다. 캐시와 재요청 대기는 제공자 인스턴스 메모리에만 유지됩니다.

## APK 문자열·외부 원본 구분

자체 화면·안내·오류·기본값과 자산, 바이너리 리소스 및 DEX 문자열을 검사했습니다. 검사 도구는 APK에 포함하지 않습니다. 개인 경로·인증정보가 발견되면 파일과 유형만 출력하며 값은 출력하지 않습니다. 패턴 검사이므로 모든 형태의 민감정보 부재를 보장하지는 않습니다. 글꼴은 fontTools로 이름·저작권 문자열을 읽으며 글자 윤곽 데이터를 일반 문장으로 해석하지 않습니다.

MediaPipe 네이티브 라이브러리 4개에는 제작사 빌드 경로 메타데이터가 있습니다. APK의 각 파일을 공식 `tasks-core:1.1.1` AAR 원본과 대조해 바이트 동일성을 확인했습니다. [파일별 SHA-256·출처](upstream-native-metadata.json)에 따라 이 항목만 별도로 표시하고 원본을 수정하지 않았습니다. 현재 사용자 홈·작업 경로 또는 토큰 패턴은 이 예외로 제외하지 않습니다.
