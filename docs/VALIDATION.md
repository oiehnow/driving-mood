## 분석에서 추천까지

Pretendard Variable을 앱 테마와 생성되는 대화상자·목록 항목에 적용했습니다. 글꼴의 이름·저작권 문자열은 fontTools로 구조를 읽어 검사하며 글자 윤곽 데이터를 일반 문장으로 해석하지 않습니다. 별도 검사에서 인위적으로 넣은 경로·토큰·검사 대상 문구를 탐지하고 손상된 글꼴을 거절하는 것을 확인했습니다. 실제 Android 단말의 글리프·가변 굵기 렌더링은 미검증입니다.

원하는 분위기 10종의 다중 선택·적용·취소·해제, 회전 후 선택값 보존, 진행 중 변경 차단, 완료 snapshot 재사용을 확인했습니다. 선택한 우울·활기 넘침의 출처는 사용자 선택으로 표시하고 실제 감정을 추론하지 않습니다. 유효한 차가운 색감의 경계, 무효/오래된 영상·고속도로 억제, 선택값의 검색어·곡 태그 가중치 연결과 해제 후 복귀도 검사했습니다. 새로 추가된 Lint 경고 1개는 원하는 분위기 요약 문자열 결합에 대한 다국어 처리 권고입니다.

버튼으로 시작하는 단발 분석을 검증했습니다. 실제 Activity와 환경·추천 서비스를 Robolectric에서 연결해 권한 거절 시 부분 결과 완성, 중복 탭 방지, 권한 창의 일시중지와 실제 백그라운드 이동 구분, 취소·60초 시간 초과 뒤 늦은 권한 응답 무시, 화면 복귀의 자동 수집 방지, 회전 후 완료 결과·분석 시각 보존을 확인했습니다. 음악 추천 갱신은 완료된 동일 snapshot을 재사용합니다.

주입한 환경·카메라 콜백으로 환경 완료 후 최신 영상 처리 순서, 이전 요청 결과 배제, 환경/영상 제한시간, 카메라 오류의 부분 결과, 취소 시 카메라 대기 해제, 완료 결과 보존을 검사했습니다. 실제 CameraX 자원 해제와 네이티브 추론은 아래 실기기 검증 범위로 남습니다.

환경 검사 34개는 모의 위치·시계·통신을 사용합니다. 동일 캐시 재사용, 10분 갱신 구간과 격자 변경, 중복 요청, 실패·쿼터 대기, 취소 후 늦은 응답 배제, 키 인코딩 및 통신 제한시간을 확인했습니다. 실제 기상청 서버 호출은 수행하지 않았습니다. 캐시와 재요청 대기는 제공자 인스턴스 메모리에만 유지됩니다.

실제 `UrbanLightAnalyzer`에 작성한 픽셀과 모의 검출기 출력을 전달하고 실제 추천기를 실행했습니다. 유효한 따뜻한 색/차가운 색 측정에서 `LOW_CONFIDENCE`와 의미 신뢰 미평가 상태를 유지하면서 분위기·검색어가 달라졌습니다. 동일한 난수 조건을 적용해 측정 색감이 후보 가중치에 도달하는지도 확인했습니다.

차량 영역 제외, 심한 어둠, 추론 실패, 오래된 영상과 고속도로 맥락에서 색감 반영 억제를 확인했습니다. 광량만으로 상권·영업·활기를 추정하지 않습니다. 이 검사는 제품 측정·추천 연결의 회귀 검사이며 네이티브 모델 정확도나 실카메라 성능 검증은 아닙니다.

## APK 문자열·외부 원본 구분

자체 화면·안내·오류·기본값과 자산, 바이너리 리소스 및 DEX 문자열을 검사했습니다. 검사 도구는 APK에 포함하지 않습니다. 개인 경로·인증정보가 발견되면 파일과 유형만 출력하며 값은 출력하지 않습니다. 패턴 검사이므로 모든 형태의 민감정보 부재를 보장하지는 않습니다.

MediaPipe 네이티브 라이브러리 4개에는 제작사 빌드 경로 메타데이터가 있습니다. APK의 각 파일을 공식 `tasks-core:1.1.1` AAR 원본과 대조해 바이트 동일성을 확인했습니다. [파일별 SHA-256·출처](upstream-native-metadata.json)에 따라 이 항목만 별도로 표시하고 원본을 수정하지 않았습니다. 현재 사용자 홈·작업 경로 또는 토큰 패턴은 이 예외로 제외하지 않습니다.
