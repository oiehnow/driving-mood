## 실제 영상과 모델 비교

실제 차량 주행 영상의 프레임으로 하늘 통계·공용 계산·음악·조명 전달을 확인했다. 별도 데스크톱 시연은 같은 프레임에 조명·사람 분할 근거를 더하고 시간 구간별 기여를 누적했다. [90초 시연과 계산 원장](product/VIDEO_DEMO.md)

Pilot02는 분리한 학습 자료로 30에폭·360회 실제 학습했지만 간판 오탐과 기존 보도·사람 성능 퇴행으로 기준 모델을 유지했다. [파인튜닝 비교](vision/finetuning02/README.md)

## 실제 기기에서 확인할 항목

실행 검증은 Android 15 x86_64 에뮬레이터에서 수행했다. Galaxy S25+의 촬영·GPS·기상청 실통신·음원 청취·발열과 지속 실행, Pleos 차량 연결은 대상 기기에서 확인한다.
