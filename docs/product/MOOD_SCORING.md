# 관측 근거로 계산하는 무드

Driving Mood는 영상에서 얻은 관측을 무드별 점수로 해석한다. 모델이 찾은 사람·차량·조명과 점수 규칙을 분리해, 어떤 요소가 결과에 기여했는지 설명한다.

![관측과 객체별 기여, 시간 구간 누적 및 무드 결과의 연결](assets/driving-v2/scoring-pipeline.png)

## 현재 규칙: scene-v2.0

0.3.0은 30초·60초 영상을 촬영한 뒤 실제 영상 시각으로 1초마다 대표 프레임을 분석한다. 색 분포와 밝은 면적의 **관측 강도**, 사람·하늘·날씨의 **맥락 점수**, 음악 후보를 정하는 **지속 조건**을 구분한다.

| 관측 강도 | 프레임별 계산 |
|---|---|
| 따뜻한 색감 | `70 × 빨강·노랑 범위의 픽셀별 채도 합 / 전체 프레임 픽셀 수` |
| 차가운 색감 | `70 × 청록·파랑 범위의 픽셀별 채도 합 / 전체 프레임 픽셀 수` |
| 밝은 면적 | `35 × 중복을 제거한 관측 픽셀 수 / 전체 프레임 픽셀 수` |
| 영역별 기여 | 해당 영역의 실제 채도 합·면적으로 위 기여를 배분 |

측정 품질은 별도로 보관한다. RGB 한두 채널이 상한에 가깝더라도 관측된 색은 유지하고, 세 채널이 모두 상한인 픽셀은 색 미확인 범주로 분리한다. 따뜻한 빛과 차가운 빛이 함께 나타나면 각각의 기여를 유지한다.

색 해석은 관측 면적 0.1% 이상, 색 분류 가능 픽셀 절반 이상인 구간에서 채도 합의 구성비를 사용한다. 한 색군이 60% 이상이면 해당 색감, 두 색군이 각각 20% 이상이고 합계 60% 이상이면 혼재 후보가 된다. 촬영 기간의 절반 이상에서 조건이 이어질 때 구간 후보로 채택한다.

시각적 활력은 관측 면적 2% 이상과 2×2 공간 중 두 구역 이상의 분포가 지속되는지를 평가한다. 사람 검출과 분포한 밝은 영역이 함께 지속되는 조건도 별도로 사용한다. 품질이 평가되지 않은 사람 분할 면적은 이 동시 조건의 사람 검출로 대체하지 않는다.

사람·하늘·날씨는 아래 기준 규칙의 독립적인 기여를 보존한다. 새 빛 강도를 사용하는 프레임에는 이전 주변 조명·간판·대표 색조 점수를 중복 합산하지 않는다. 실제 Android 관측은 `accepted-light-rgb-v1`, 의미분할 보조 연구 관측은 `semantic-contrast-rgb-v3`로 버전을 구분한다.

## 물체와 점수의 연결

| 관측 | 계산에서 맡는 역할 | 화면 표시 |
|---|---|---|
| 사람 검출 박스 | 활력의 근거. 한 프레임의 검출 수에 상한 적용 | 사람 영역과 해당 기여 점수 |
| 차량을 제외한 주변 조명 후보 | 조명 수·면적·화면 내 분포에 따른 활력 근거 | 조명 후보와 그룹 기여의 배분값 |
| 차량 박스 | 차량 불빛이 주변 조명에 섞이지 않도록 제외 | 조명 계산 제외 |
| 차량 제외 색감 | 따뜻함·차가움의 근거 | 색감의 기여 및 반대 근거 |
| 실제 의미분할의 하늘·간판 후보 | 하늘 밝기와 중복을 제외한 간판의 밝은 면적 | 의미분할 후보라는 출처와 반영 여부 |
| 위치·도로·날씨 | 영상 해석의 맥락과 적용 조건 | 실제 출처, 시각, 수동 입력 여부 |

점수는 관측을 해석하는 초기 규칙값이며 인식 모델의 오차에 영향을 받는다.

그룹 기여를 실제 참조 영역에 분배하며 배분값의 합은 계산 원장과 일치한다. 박스 ID는 프레임 단위로 관리한다.

### 간판의 밝은 부분을 계산하는 방법

실제 간판 분할 영역과 공통 밝기 측정을 같은 픽셀 격자에 맞춘다. 차량·교통등·반사·과노출 등 제외 조건을 적용한 뒤, 이미 주변 조명으로 채택된 픽셀을 빼서 추가로 반영할 면적을 구한다.

`간판의 추가 밝은 영역 = 유효한 간판 밝은 픽셀 − 이미 채택된 주변 조명 픽셀`

간판별 점수는 이 추가 면적에 비례한다. 어두운 간판이나 주변 조명에 완전히 포함된 간판은 추가 기여가 0이다. 측정하지 못한 항목은 0으로 채우지 않는다. 위치를 모르는 경우에도 이 제한적인 시각 근거를 사용할 수 있으며, 유효하게 확인된 고속도로에서는 간판의 활력 기여를 억제한다. GPS·영업시간은 상업적 맥락을 보완하는 후속 정보다.

간판 마스크와 밝은 픽셀의 프레임 전체 합계만 있는 입력에는 개별 간판 점수를 만들지 않는다. 모든 간판 성분의 실제 면적·중복 면적·영역 ID가 연결된 입력만 사용한다. 작은 글자나 간판을 모델이 건물로 분류했다면 그 누락도 그대로 남는다.

### 초기 점수 규칙: scene-v1.2

0.2.5의 기준 규칙이다. 면적은 전체 프레임 대비 비율이며, 품질 계수는 측정 조건을 반영한다.

| 근거 | 한 시간 구간의 계산 |
|---|---|
| 사람 검출 | `55 × min(검출 수 / 5, 1) × 사람 측정 품질` |
| 주변 조명 | `35 × (0.4 × 수 정규화 + 0.3 × 면적 정규화 + 0.3 × 분포) × 조명 측정 품질` |
| 조명 수·면적·분포 | 수는 8개, 면적은 화면 20%에서 제한. 분포는 후보 중심이 차지한 2×2 구역의 비율 |
| 간판 추가 밝기 | 평가된 품질이 있으면 `10 × min(추가 면적 / 0.1, 1) × 품질`. 품질 미평가는 별도 `5 × min(추가 면적 / 0.05, 1)` |
| 따뜻함·차가움 | 해당 색상 구간의 채도와 유효 색감 품질에 최대 70점. 반대 색감은 자기 양의 기여 이내에서 상쇄 |
| 하늘 밝기 | 하늘 평균 밝기와 면적(화면 30%에서 제한)에 최대 25점 × 품질. 품질 미평가 입력은 별도 최대 10점 |
| 날씨 | 실제 기온·강수 정보가 제공될 때 적용. 기온은 18°C 중심 ±12°C 범위의 초기 규칙이며 강수는 청량 축을 제한적으로 상쇄 |

사람 검출이 양수인 구간에는 사람 분할 면적을 추가하지 않는다. 검출의 양의 근거가 없는 구간에서는 출처가 있는 실제 데스크톱 사람 마스크를 별도의 제한된 면적 근거로 사용할 수 있다. 이것을 인원수로 변환하지 않는다.

키워드는 따뜻함·차가움 15점, 청량함 20점부터 후보가 된다. 활력은 35점 이상이거나 조명 기여가 20점 이상이며 유효 조명 구간의 절반 이상에서 여러 조명의 분포 조건을 충족할 때 후보가 된다. 분포 조건은 후보 3개 이상·면적 2% 이상·4개 구역 중 2개 이상이다. **사람은 활력 후보의 필수 조건이 아니다.** 문턱 미만에서도 실제 근거 점수는 표시한다.

## 이전 기준선의 50초 관측

0.2.5는 위치·날씨 조회와 함께 최대 50초의 카메라 관측을 모았다. 1초 구간별 대표 관측과 평균 계산은 현재 30초·60초 창에도 이어진다.

각 구간의 관측값을 정규화하고 요소별 가중치를 적용한다. 유효 구간의 기여를 평균하여 프레임 처리 속도가 빠르거나 같은 사람이 오래 보인다는 이유만으로 점수가 계속 증가하는 것을 막는다. 누락 구간을 사람0명이나 조명0개로 채우지 않는다. 관측 종료 이후의 프레임은 결과에 들어가지 않는다.

`관측값 정규화 × 요소별 가중치 × 해당 관측의 적용 가능한 품질 계수`

기여 원장은 관측값·단위·가중치·가산 또는 감점·미반영 이유·영역 참조를 함께 보관한다. 차량을 이미 조명 측정에서 제외했다면 차량 점유율을 이용해 같은 기여를 다시 깎지 않는다. 부족한 근거를 자동으로 우울함이나 차분함으로 바꾸지 않는다.

## 이전 시연 구성

| 구간 | 화면 내용 |
|---|---|
| 0–50초 | 실제 주행 프레임의 물체 박스와 현재 기여 점수, 시간 구간별 누적 점수 |
| 50–80초 | 관측한 프레임과 계산 원장을 이용한 근거 설명 |
| 80–90초 | 최종 환경 키워드·무드별 점수·주요 기여 |

데스크톱 분석 시연의 편집 구성이다. 짧은 원본은 실제 관측 구간에 근거 설명과 결과를 이어 붙인다.

## 지도와 영업정보를 결합하는 방향

아파트 창문과 가게 조명을 구별하기 위해 위치·카메라 방향·건물 배치·장소 유형·등록 영업시간을 대조하는 방식을 계획한다.

내비게이션·상권·영업시간 API 연동은 후속 개발 항목이다.

## 인식 모델과 점수 규칙의 개선

간판, 주거 창문, 매장 창문, 차량 불빛, 가로등과 반사를 더 잘 구별하려면 인식 모델의 학습 데이터를 준비하고 평가해야 한다. 기존 예측을 정답으로 바꾸지 않고, 주행 단위로 학습과 검증을 분리해 인접 프레임의 중복을 막는다. 무드 가중치 조정은 이 모델 학습과 별도로 버전을 관리한다.

같은 실제 입력으로 성능을 비교하고, 단말 성능은 별도로 측정한다. 사진·마스크·프레임 계산·모델 비교는 [시행착오 자료](TRIALS.md)에 정리했다.
