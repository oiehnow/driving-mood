# 시행착오 검토 자료

보고서 본문은 실제 확인된 결과와 개선 근거를 중심으로 읽고, 대표 오류는 아래 4개만 비교한다. 전체 실패 프레임을 본문에 반복해서 배치하지 않는다.

![차량 실내, 도로 안내판, 빗물 반사, 오토바이 차체의 대표 오류 4개](assets/driving/trial-errors-four.png)

첫 번째와 세 번째는 모델의 분할 오류다. 두 번째는 표지판 분류가 맞더라도 상점 간판으로 해석해서는 안 되는 의미 연결의 문제다. 네 번째는 촬영 차량 자체와 전방 차량을 구분해야 하는 문제다. 오류 원인을 분리해야 모델 교체와 후처리 개선 효과를 비교할 수 있다.

원본 영상, 모델별 체크포인트, 전체 RGB·ID 마스크·프레임별 계산값과 실행 기록도 작업 자료로 유지한다. 대표 그림을 바꿔도 원본 검증 자료는 삭제하지 않는다. 아직 실행하지 않은 모델의 성공이나 개선 효과를 기존 결과에 덧붙이지 않는다.
