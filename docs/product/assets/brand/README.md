# Driving Mood 아이콘

`driving-mood-icon.png`는 노을과 굽이치는 길을 주제로 새로 제작한 대표 이미지다. 앱 런처와 홈 헤더에서 사용한다. 제작자: **oieh**.

대표 이미지는 내장 이미지 생성 도구로 제작했다. 디자인 요청은 “네이비 바탕, 살구빛 노을, 부드럽게 이어지는 입체적인 길, 작은 크기에서도 읽히는 단순한 형태, 문자와 워터마크 없음”이다.

화면 내 조작 아이콘은 [Phosphor Icons](https://github.com/phosphor-icons/core)의 duotone을 사용한다. [원본·버전·변환 기록](phosphor/sources.json)과 [MIT 라이선스](phosphor/LICENSE.txt)를 보존했다.
