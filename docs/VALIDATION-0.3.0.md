## 녹화와 분석

30초 또는 60초 무음 영상을 CameraX Recorder로 앱 내부 캐시에 기록합니다. 파일 저장이 완료된 뒤 MediaExtractor/MediaCodec의 실제 presentation timestamp 순서로 디코딩하고 1초 구간별 프레임을 분석합니다. 영상 길이와 끝 프레임 도달을 확인하며, 촬영 시각과 분석 완료 시각을 분리합니다. 완료·실패·취소 후 임시영상을 삭제합니다.

단위·통합 검사에서 시간 원점, 중복·역순 PTS, 30/60초 경계, 불완전 영상 기간 거절, YUV 변환, 위치·날씨 병행, 권한 거절·취소·제한시간, 늦은 응답 배제, 이전 완료 결과 보존, 완료음 요청당 한 번을 확인했습니다. 회전 시 촬영은 취소하고 완료 결과·촬영 길이·조명 선택은 유지합니다.

네이티브 검사는 Android Emulator 37.2.12 / Android 15 API 35 x86_64 / 가상 카메라에서 debug APK로 수행했습니다.

- 실제 30초·60초 파일 → 디코딩 → B 관측 → C 추천 → 완료 결과, 각각 30개·60개 장면.
- 실제 길이 선택 화면과 `ANDROID_RECORDED` 출처, 증가하는 영상 시각, 완료음 중복 방지.
- 녹화 중 백그라운드 이동과 디코딩 중 취소: 결과 미확정, 자동 재시작 없음, 임시영상 0개.
- 360×640 디코딩 영상과 ImageView·근거 표시 영역의 동일 크기/FIT_CENTER 확인, 화면 직접 검토.
- 완료음 리소스 로딩과 SoundPool 재생 스트림 생성. 청취 평가는 수행하지 않았습니다.

최종 서명 release는 같은 에뮬레이터에서 0.2.5 위에 업데이트 설치하고 앱 실행을 확인했습니다. 가상 카메라 장면에는 유효한 도시 물체 박스가 없어 실제 주행 물체의 박스 정렬 정확도는 이 검사에 포함하지 않습니다.

## 관측·추천 연결

Android는 기존 채택 픽셀의 실제 RGB 분포·색별 채도합·면적을 `accepted-light-rgb-v1`로 제공합니다. 색감과 밝은 면적의 강도는 측정 품질과 분리합니다. 사람·하늘·날씨의 기존 점수와 새 빛 강도는 별도 항목으로 표시하며, 지속 관측 조건으로 음악 후보를 만듭니다.

실제 B 분석기와 C 누적·추천기를 연결해 색감 유지, 차량 제외, 고속도로에서 시각적 활력 후보 제한, 촬영 종료 시각에 따른 신선도, 불완전 입력 거절, 중첩 목록 방어 복사를 검사했습니다. 사람·하늘·날씨 근거 보존과 로컬 음원 카탈로그 가중치·사용자 목표 우선·최근 곡 회피·빈 카탈로그 회귀도 전체 검사에 포함했습니다.

현재 프레임의 영역과 기여만 연결하며, 영역별 기여 합계가 일치할 때 숫자를 표시합니다. 미측정과 실제 0을 구분하고 가산점 없는 관측 통계는 값과 단위로 표시합니다. 조명 프리셋·밝기는 화면 미리보기로 제공합니다.

날씨 검사는 모의 위치·시계·통신으로 캐시·실패 제한·취소·키 인코딩을 확인했습니다. 실제 기상청 호출과 개인 로컬 음악 청취는 수행하지 않았습니다.

## 외부 원본

MediaPipe 라이브러리 4개에 포함된 제작사 빌드 경로는 공식 `tasks-core:1.1.1` AAR과 바이트 동일성을 확인한 [원본 메타데이터](upstream-native-metadata.json)로 별도 기록합니다. 사용자 경로·토큰은 이 예외에 포함하지 않습니다. APK 검사는 패턴 기반이며 글꼴 윤곽 데이터는 UI 문장으로 해석하지 않습니다.
