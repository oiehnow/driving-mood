Driving Mood requests nearby road geometry from the public Overpass API only when
the user starts an analysis. Precise coordinates are sent for this lookup.
This is a nearby mapped road estimate, not confirmed navigation map matching.
The app displays attribution and missing/ambiguous/timeout states.
