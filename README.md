# Driving Mood

주변 환경과 운전자 맥락에서 **무드 키워드를 추출하고 다양한 경험에 연결하는 앱**을 개발합니다. 공통 무드 엔진을 중심으로 운전자의 취향·선택·피드백을 반영하고, 음악·차량 실내조명·근처 갈 만한 곳 추천 등으로 확장하는 것이 목표입니다.

현재 Android 프로토타입은 사용자가 **무드 분석**을 누를 때 위치·날씨를 확인하고 짧게 카메라를 분석해 키워드를 만듭니다. 완료하면 수집을 멈추고 분석 시점의 결과를 유지합니다. 공통 엔진의 독립 모듈화, 운전자 감성 피드백, 차량 연동과 장소 추천은 후속 개발 항목입니다. 주변 풍경만으로 운전자의 실제 감정을 확정하지 않습니다.

![무드 키워드와 현재 음악 활용, 후속 차량 경험 확장](docs/product/assets/mood-overview.png)

## 원하는 분위기

**차가운 / 우울 / 활기 넘침**을 비롯해 따뜻한·몽환적인·차분한·잔잔한·편안한·포근한·청량한 분위기를 선택할 수 있습니다. 선택한 목표는 음악 추천에 우선 반영합니다.

후속 방향은 환경 무드와 음악의 방향을 분리해 **분위기를 이어가기 / 다른 분위기로 전환하기**를 선택지로 제안하는 것입니다. 다양한 환경 무드의 판단 기준과 이 제안 흐름은 아직 설계 단계입니다. [용어 정의](CONTEXT.md)

![차가운 색감 단서와 사용자가 선택하는 우울·활기 넘침의 구분](docs/product/assets/mood-keywords.png)

같은 지역의 유효한 날씨 결과를 재사용해 조회를 줄입니다. 분석 완료·취소 시 수집을 멈추며, 권한 거부나 입력 누락은 결과에 표시합니다. 사용자 취소 시 이전 완료 결과를 유지합니다.

## 무드 키워드를 만드는 과정

차량 영역을 제외한 색감·밝기를 측정하고, 품질 조건을 통과한 단서만 시간·날씨·도로 맥락과 결합합니다. 고속도로로 지정되거나 색감이 불확실하면 영상 색감의 반영을 제한합니다.

## 실제 주행 영상 분석

사용자 제공 주행 영상의 실제 프레임에 의미 분할 모델과 기존 Kotlin 무드 계산을 실행했습니다. 원본·분할 결과·측정값이 같은 영상 시각에 대응합니다. 생성 이미지는 입력으로 사용하지 않았습니다.

![실제 야간 주행 프레임과 세그멘테이션 및 무드 계산](docs/product/assets/driving/clip-01-analysis.gif)

이 자료는 **데스크톱에서 실행한 분할 모델의 시연**입니다. 현재 APK 화면 녹화가 아니며, 새 분할 모델은 아직 앱에 탑재하지 않았습니다. 촬영 당시 GPS·날씨·시각이 없는 경우 임의로 보충하지 않습니다. 근거가 부족하면 무드 결과를 ‘판단 보류’로 표시합니다.

## 시작하기

Android 8.0 이상에서 사용할 수 있습니다. APK 빌드와 설치 방법은 [빌드 안내](docs/BUILD.md)를 참고하세요.

1. 날씨를 사용하려면 **기상청 키 설정**에서 공공데이터포털의 초단기실황 API 키를 입력합니다. 키 설정만으로 조회하지 않으며, 키 없이도 분석할 수 있습니다.
2. **무드 분석**을 누르고 카메라·위치 권한을 확인합니다. 위치·날씨 확인 후 짧은 영상 분석을 진행합니다.
3. 완료된 키워드와 분석 시각, 사용하지 못한 정보를 확인합니다. 새 결과가 필요할 때 다시 분석합니다.
4. **원하는 분위기**를 선택하고 **로컬 음원 선택**으로 음악을 추가합니다. 곡별 태그와 선호 장르를 지정해 재생합니다. 분위기 변경과 음악 조작은 새 카메라·위치·날씨 수집을 시작하지 않습니다.

카메라 영상은 저장·전송하지 않습니다. 날씨 조회에는 위치를 변환한 기상청 격자와 조회 시각을 사용합니다. API 키와 선택한 음악 목록은 앱 실행 중에만 유지됩니다. 직접 입력한 환경 정보는 실제 관측값과 구분해 표시합니다. 분석 결과는 표시된 시점의 기록이며 자동 갱신되는 현재 상태가 아닙니다.

## 현재 지원 범위

현재 영상 분석은 **EfficientDet Lite0 차량 검출과 픽셀 기반 색감·밝기 측정**입니다. 건물·간판의 의미 분할, 자동 도로 분류와 차량 내비게이션 연결은 후속 항목입니다. 분석값은 조명 특성이며 점포의 영업 여부를 판단하지 않습니다. 작은 차량·반사광을 놓칠 수 있습니다.

측정이 충분한 경우 조명의 색감을 음악 분위기에 반영합니다. 실제 휴대폰에서의 전체 동작 검증은 완료되지 않았습니다. 검증 기준과 결과는 [검증 기록](docs/VALIDATION.md)에 정리했습니다.
